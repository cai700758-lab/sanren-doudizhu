# 三人局 · 联机斗地主

[![部署到 Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/cai700758-lab/sanren-doudizhu)

点击上方按钮，在自己的 Render 账号中选择 **Free** 部署完整游戏服务。部署成功后，将平台生成的 HTTPS 游戏地址分享给朋友，即可跨设备、跨网络进入同一房间。

一个支持真人联机和机器人补位的斗地主网页游戏。1 人、2 人或 3 人都能玩。绿色牌桌与卡通人物界面，手机、平板和电脑通过浏览器进入同一房间。无需注册，无需安装客户端。

大厅可选择**经典模式**或**技能模式**，房间模式在创建时确定，加入者自动使用房间模式。

技能模式每人发牌时独立随机获得一个主动技能，允许同桌技能重复；在自己的出牌回合可使用一次，使用后继续出牌且不重置计时。机器人也会使用技能。新局重新分配，断线保留当前技能和使用状态。

| 技能 | 效果 |
| --- | --- |
| 万能牌 | 最大手牌变为万能牌，出牌前可指定 3～A、2、小王或大王；点击技能按钮修改点数，提示也会计算万能牌。 |
| 赠牌 | 将一张自选手牌交给另一名玩家。 |
| 换牌 | 将一张自选手牌替换为随机牌。 |
| 弃小牌 | 删除最小的一张手牌，同点数只删一张。 |
| 复制 | 随机复制一张自己的手牌。 |
| 摸三张 | 加入三张随机牌。 |
| 三选一 | 抽取三个仅本人可见的候选，选择一张加入；重连可继续选择，超时自动选第一张。 |
| 知己知彼 | 指定一名玩家，随机查看最多三张手牌，仅使用者可见；保留使用时的快照，刷新可继续查看。 |
| 步步高升 | 选择一张牌升一级：3～A、2、小王、大王。2 可变小王，小王可变大王；大王和万能牌不能升级。 |

随机牌按标准 54 张牌有放回抽取，可重复，但每张实体牌拥有独立标识。新增手牌仍遵守经典牌型，五张同点数不算炸弹。**赠牌或弃小牌清空手牌直接获胜**。所有使用次数、目标、随机结果和万能牌点数都由服务器验证。

界面参考多邻国的布局与按压反馈：桌面侧边导航、手机顶部工具栏、立体按钮、选牌抬起和高亮。保留简洁操作文案。

「反馈设置」可独立开关触感反馈和牌桌音效，设置保存在当前浏览器。音效默认开启，已保存的静音设置仍然有效；点击页面后启用声音。洗牌、落牌、不出、炸弹、剩牌提醒和胜负有独立音效；切到后台或关闭声音会停止播放。振动在支持的设备上开启，遵循系统减少动态效果设置。不支持振动时仅提供视觉按压反馈，浏览器可能限制振动或声音播放；自动测试验证调用逻辑，不代表已在实体手机上验证震感。[振动 API 兼容性说明](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/vibrate)。

炸弹与王炸会延长展示时间；剩余一两张牌时显示提醒；结算展示胜负和本局得分。提示浮在牌桌上，不改变牌桌高度，也不拦截操作。刷新和重连不会重播已发生的特效，系统开启减少动态效果时保留文字提示。

特殊牌型有独立动画：顺子逐张展开、连对成组跳动、飞机掠过、三带和四带聚拢、炸弹冲击波、王炸双火箭升空。装饰牌使用本次出牌的点数和花色，动画仅叠加在牌桌上，不影响实际出牌区与选牌。

## 立刻开玩

### Windows 一键启动

1. 双击本目录的 **`start.cmd`**。需要 Node.js 22 或更新版本，首次运行会自动安装依赖。
2. 启动窗口会显示本机地址和局域网地址。
3. 主机浏览器打开 **http://localhost:3000**，填写昵称，点击「创建好友房」。
4. 三个人在同一个 Wi-Fi 时，另外两台设备访问启动窗口中 **WLAN 对应的局域网地址**，例如 `http://192.168.1.10:3000`，填写昵称和房间码。
5. 三个人各点「准备开局」，自动发牌。轮到自己时叫分或选牌出牌。

建议主机也使用局域网地址打开游戏，然后点击「邀请好友」复制链接；朋友打开链接时会自动填好房间码。`localhost` 只代表当前设备，不能直接分享给别人的手机。

启动窗口需要保持运行。关闭窗口、按 Ctrl+C，或双击 `stop.cmd` 会停止服务，当前房间和积分随之清空。`stop.cmd` 只停止由本目录绝对路径启动的游戏服务，不会停止其他 Node.js 项目。

### 命令行启动

```powershell
npm.cmd ci
npm.cmd start
```

macOS / Linux 使用 `npm ci` 和 `npm start` 即可。需要更换端口时，在 PowerShell 中运行：

```powershell
$env:PORT = '3001'
npm.cmd start
```

免费服务连续 15 分钟没有入站流量会休眠，首次唤醒可能需要约一分钟。房间目前保存在内存里，休眠、重启或重新部署后需要重新建房；适合朋友间试玩。查看 [Render 免费服务说明](https://render.com/docs/free)。

## 已实现的功能

- 6 位房间码建房 / 加入，房间最多 3 人；邀请链接自动填好房间码。
- 三人准备后自动发牌；每人 17 张，地主拿 3 张底牌；对局中仅本人能收到自己的手牌，结算后公开三人剩余手牌。
- 0 / 1 / 2 / 3 分叫地主，叫 3 分立即确定；三人不叫重新发牌。
- 单张、对子、三张、三带一、三带二、顺子、连对、飞机及翅膀、四带二、四带两对、炸弹、王炸。
- 服务器验证手牌归属、牌型、压制关系和轮次，拒绝过期操作及重复牌。
- 点击选牌 / 取消、重选、出牌提示、不出；桌面和手机自适应手牌。
- 轮到自己时，连续选牌停顿 0.6 秒后自动整理无法打出的组合：只从已选牌中筛选，优先保留最多张数，同张数优先顺子、连对和飞机，跟牌必须能压过上一手。原本合法的组合不变；无解时保留选择；“撤销”恢复整理前的选牌，不会自动出牌。
- 所有牌面从左到右由小到大排列：3 到 A、2、小王、大王；手机双排手牌按先上排后下排顺序排列。
- 左右玩家的出牌显示在各自座位下方，自己的出牌显示在手牌上方。本轮各家的出牌独立保留；不出会移除该玩家的旧出牌，两家不出后清理牌桌。刷新可恢复当前各座位的出牌。
- 按住手牌横向滑动可连续多选。从未选中的牌开始滑动为选中，从已选中的牌开始为取消；一次滑动中经过同一张牌不会反复切换。支持鼠标、触屏及跨行选择；取消触摸手势会恢复原先选择。
- 洗牌发牌约 2.5 秒，出牌飞入约 0.7 秒；服务器保留发牌展示时间和回合间约 1 秒的停顿，之后才开始下一位的思考时间。系统开启减少动态效果时跳过动画，但保持一致的联机节奏。
- “不出”在各玩家出牌区域以大字显示，保留到该玩家下次轮到行动。出牌区、手牌区和操作区预留固定空间，空牌、出牌和结算不会改变牌桌高度；窄屏上的长牌组可在各自区域横向滑动查看。
- 炸弹 / 王炸 / 春天倍数，地主和农民队伍结算，房间累计积分，三人准备再来一局。
- 45 秒回合倒计时，超时自动不叫 / 不出，领出时自动出最小单张。
- 原标签页刷新或临时断线恢复身份与手牌；离线座位保留 30 分钟。对局计时继续。
- 快捷消息、对局记录、手机战绩面板、房主离开自动转移房主。

### 一个人或两个人玩

创建房间后，房主点击「机器人补位」，自动填满剩余的 1–2 个座位。机器人默认准备，真人玩家点击「准备开局」即可开始。

机器人在展示停顿结束后约 2.2 秒自动叫分和出牌，能使用顺子、连对、飞机等牌型，农民机器人会尽量配合队友。策略只使用自己的手牌和公开信息，不查看其他玩家的手牌。这是基础策略机器人，不是专业对战 AI。

每局结束后持续展示剩余手牌与准备人数。机器人自动准备，所有真人点击「准备下一局」后才会重新发牌；取消准备或断线会继续等待。开局前或结算后，房主可以点击机器人座位下的「移除」。好友加入已坐满的等待房间时，会自动替换一个机器人；进行中的对局不能换人。最后一位真人离开后，机器人和房间会一起清理。

## 本桌采用的规则细节

斗地主地区规则存在差异，本实现固定如下，游戏内「游戏规则」也可查看：

- 普通牌需要同牌型、同张数且主体点数更大；炸弹压普通牌，王炸最大。
- 顺子至少 5 张，连对至少 3 对，飞机至少 2 组连续三张。主体不含 2 或王。
- 飞机的单翅膀可成对，但不复用主体点数，不允许四张同点数充当翅膀，也不能同时带双王；对子翅膀必须为不同点数的对子。
- 四带二张可以带一对，不能同时带双王；四带两对要求两个不同点数的对子，不能带一个炸弹。
- 叫分为初始倍数，炸弹、王炸和春天各翻倍。地主胜且农民没出过牌，或者农民胜且地主只出过一次牌，算春天。
- 地主得失两份积分，两位农民各得失一份，三人积分变化之和为零。
- 主动离开会取消正在进行的本局，不计分。留下的人可以邀请新玩家。
- 积分仅为房间内的游戏记录，不涉及金钱。

## 常见问题

**手机打不开页面**

确认手机与主机连接同一 Wi-Fi，并访问主机的 WLAN IPv4 地址。Windows 首次弹出 Node.js 防火墙提示时允许专用网络访问。访客 Wi-Fi、AP 隔离、VPN 或公司网络策略可能禁止设备互访。主机切换网络后，地址可能变化，以启动窗口当前输出为准。

**电脑有多个地址，选哪个？**

启动窗口可能同时显示 VPN、虚拟网卡和 WLAN 地址。PowerShell 中运行 `Get-NetIPAddress -AddressFamily IPv4`，选择你实际联网的 WLAN 或以太网网卡。不要使用 `127.0.0.1` 或 `169.254.*` 给朋友连接。

**无法自动复制邀请链接**

部分浏览器在 HTTP 局域网环境下限制剪贴板。游戏会尝试兼容复制；若仍不可用，长按链接或 Ctrl+C 手动复制即可。

**一台电脑上测试三个人**

打开三个独立新标签页并输入不同昵称。不要使用「复制标签页」功能，因为浏览器可能复制 sessionStorage；若提示座位已接管，重新打开一个空白标签页再输入地址。自动浏览器测试使用三个互相隔离的浏览器上下文。

**刷新后能回来吗？**

使用原标签页刷新或等待自动重连可以恢复。身份令牌存在该标签页的 sessionStorage；关闭标签页、清理浏览器数据或换浏览器不保证恢复。相同令牌同时连接时，以最近打开的页面为准。

$env:BROWSER_CHANNEL = 'chromium'
